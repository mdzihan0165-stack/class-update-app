# 🚀 Full-Stack Kotlin Multiplatform Workspace

A unified cross-platform application and server architecture built with **Kotlin Multiplatform (KMP)** and **Compose Multiplatform**. This template shares UI, state management, and business logic across **Android**, **iOS**, **Desktop**, and **Web**, backed by a high-performance **Ktor** server.
